১. ফেসবুক পেজ পারমিশন — ম্যানুয়াল সেটআপ (Step-by-Step) 1. Facebook Page Permission — Manual Setup Guide

কীভাবে ফেসবুক ডেভেলপার প্যানেলে ম্যানুয়ালি আপনার পেজ ও অ্যাপ কানেক্ট করবেন। Step-by-step instructions to configure Meta Developer Console and Webhooks.

🚨 ⚠️ আবশ্যক শর্ত (App Type MUST be Business):
ফেসবুক অ্যাপ তৈরির সময় App Type অবশ্যই "Business" নির্বাচন করতে হবে! "Business" টাইপ সিলেক্ট না করলে ফেসবুক মেসেঞ্জার ও পেজ প্রোডাক্ট যুক্ত হবে না এবং সিস্টেমে পেজের মেসেজ/কমেন্ট এপিআই কাজ করবে না। App Type MUST be selected as "Business" during app creation! Non-business app types do NOT support Page Messenger API or Webhooks subscription.
  1. Facebook Developers-এ লগইন করুন:
    সরাসরি developers.facebook.com-এ প্রবেশ করুন এবং আপনার ফেসবুক অ্যাকাউন্ট দিয়ে লগইন করে My Apps -> Create App-এ ক্লিক করুন।
  2. Business App Type নির্বাচন করুন (বাধ্যতামূলক):
    App type হিসেবে অবশ্যই "Business" নির্বাচন করুন এবং আপনার অ্যাপের নাম দিন (যেমন: My Business Bot)।
  3. Product যোগ করুন (Facebook Login for Business & Webhooks):
    Add Products থেকে Facebook Login for Business এবং Webhooks প্রোডাক্ট দুটি যুক্ত করুন।
  4. Webhook Callback URL এবং Verify Token দিন:
    ইনসাফ এআই ড্যাশবোর্ডের Facebook Settings থেকে আপনার ইউনিক Callback URL ও Verify Token কপি করে ফেসবুক Webhooks-এ বসান।
  5. ম্যানুয়াল পারমিশন অন করুন:
    App Review -> Permissions and Features সেকশনে গিয়ে নিচের প্রয়োজনীয় পারমিশনগুলো রিকোয়েস্ট বা অনুমোদন দিন।
  1. Log in to Facebook Developers:
    Navigate to developers.facebook.com and click My Apps -> Create App.
  2. Select Business App Type (Mandatory):
    Choose "Business" as your app type and assign your app name (e.g. My Business Bot).
  3. Add Products (Facebook Login for Business & Webhooks):
    Add Facebook Login for Business and Webhooks products from the Meta dashboard.
  4. Configure Webhook Callback URL & Verify Token:
    Copy your Callback URL and Verify Token from Insaf AI Facebook Settings into the Meta Webhook configuration panel.
  5. Grant Required Permissions:
    In App Review -> Permissions and Features, grant the necessary Page permissions listed below.

২. Graph API Explorer দিয়ে সহজে পারমিশন ও অ্যাক্সেস টোকেন জেনারেট 2. Graph API Explorer — Testing & Token Generation Guide

মেটার অফিশিয়াল টুল ব্যবহার করে ফেসবুক পেজ ও কমেন্ট পারমিশন দ্রুত চেক করার নিয়ম। How to use Meta's official Graph API Explorer tool to grant and test permissions.

  1. Graph API Explorer টুলে প্রবেশ করুন:
    ব্রাউজারে সরাসরি developers.facebook.com/tools/explorer লিঙ্কটি অন করুন।
  2. Meta App নির্বাচন করুন:
    ডানপাশের **Meta App** ড্রপডাউন থেকে আপনার তৈরি করা Business App টি সিলেক্ট করুন।
  3. Permissions যুক্ত করুন:
    ডানপাশের **Permissions** সেকশনের **Add a Permission** ড্রপডাউন থেকে নিচের ৫টি পারমিশন একটি একটি করে সিলেক্ট করুন:
    • • pages_show_list
    • • pages_messaging
    • • pages_read_engagement
    • • pages_manage_metadata
    • • pages_manage_posts
  4. Get Page Access Token সিলেক্ট করুন:
    **User or Page** ড্রপডাউনে ক্লিক করে **Get Page Access Token** অপশনে প্রেস করুন এবং আপনার যে পেজে ইনবক্স ও কমেন্ট বট চালাবেন সেই পেজটি সিলেক্ট করুন।
  5. Generate Access Token দিন:
    নীল রঙের **Generate Access Token** বাটনে ক্লিক করুন। স্ক্রিনে ফেসবুক পপ-আপ আসলে পেজের সমস্ত পারমিশন **Continue** দিয়ে সেভ করুন।
  1. Open Graph API Explorer Tool:
    Open developers.facebook.com/tools/explorer in your browser.
  2. Select Meta App:
    Select your created Meta Business App from the top-right **Meta App** dropdown menu.
  3. Add Required Permissions:
    Under **Permissions**, click **Add a Permission** and select the following 5 permissions:
    • • pages_show_list
    • • pages_messaging
    • • pages_read_engagement
    • • pages_manage_metadata
    • • pages_manage_posts
  4. Select Get Page Access Token:
    Click the **User or Page** dropdown, choose **Get Page Access Token**, and select your target Facebook Page.
  5. Generate Access Token:
    Click **Generate Access Token**, review the Facebook OAuth popup prompt, and confirm all permissions.

৩. ফেসবুক পারমিশন লিস্ট ও ব্র্যাকেটে কাজের বিবরণ 3. Facebook Permission List & Capability Brackets

প্রতিটি ফেসবুক পারমিশনের নাম, ব্র্যাকেটে কাজ এবং ব্যবহারের উদ্দেশ্য। Detailed breakdown of required scopes, bracketed functions, and use cases.

pages_show_list [স্বয়ংক্রিয় পেজ শনাক্তকরণ ও নির্বাচন] [Page Discovery & Selection]
আপনার ফেসবুক অ্যাকাউন্টের অধীনে থাকা সমস্ত ফেসবুক পেজের তালিকা প্রদর্শন করে, যেন আপনি বেছে নিতে পারেন কোন পেজটিতে এআই চ্যাটবট যুক্ত করবেন। Lists all Facebook Pages managed by your account to allow seamless selection of which page to connect to Insaf AI.
pages_messaging [ইনবক্স মেসেজিং অটোমেশন ও চ্যাট] [Messenger Automation & Live Chat]
মেসেঞ্জারে কাস্টমারদের পাঠানো মেসেজ গ্রহণ করা এবং AI এর মাধ্যমে রিয়েলটাইম স্বয়ংক্রিয় উত্তর, প্রডাক্ট কার্ড ও অর্ডার নেওয়ার অনুমতি দেয়। Allows receiving customer messages in Messenger and sending real-time automated AI replies, product catalog cards, and order confirmations.
pages_read_engagement [পোস্ট ও কমেন্ট ইঙ্গেজমেন্ট রিড] [Post & Comment Reading]
আপনার ফেসবুক পেজের পোস্টের কমেন্ট, রিঅ্যাকশন এবং কাস্টমারদের দেওয়া প্রতিক্রিয়া পড়ার অনুমতি দেয়। Grants read access to post comments, reactions, and customer engagement metrics on your Facebook Page.
pages_manage_metadata [ওয়েব হুক সেটআপ ও ইভেন্ট নোটিফিকেশন] [Webhook Configuration & Realtime Events]
ফেসবুক পেজে নতুন মেসেজ বা কমেন্ট আসামাত্র সাথে সাথে ওয়েবহুক (Webhook) সিস্টেমে মেসেজ রিসেভ করার অনুমতি দেয়। Subscribes webhooks to real-time Page events so new customer messages and comments are instantly received.
pages_manage_posts [কমেন্টে পাবলিক রিপ্লাই দেওয়া] [Public Comment Publishing]
পেজের যেকোনো অফার পোস্টের নিচে কাস্টমারদের কমেন্টের নিচে পেজের পক্ষ থেকে পাবলিক রিপ্লাই দেওয়ার অনুমতি দেয়। Allows publishing public replies under customer comments on your Facebook Page posts.

৪. কমেন্ট অটো-রিপ্লাই সেটআপ ও পারমিশন গাইড 4. Comment Auto-Reply & Private DM Setup Guide

কমেন্ট অটো-রিপ্লাই চালু করতে কি কি পারমিশন লাগে এবং কীভাবে কাজ করে। How public comment auto-replies and instant private inbox messages work.

📌 কমেন্ট অটো-রিপ্লাইয়ের জন্য প্রয়োজনীয় পারমিশন: 📌 Required Permissions for Comment Automation:

1. pages_read_engagement [কমেন্ট রিড করা] [Read Post Comments]
পোস্টে কাস্টমারের নতুন কমেন্ট পড়তে ব্যবহৃত হয়। Reads new comments posted on your page posts.
2. pages_manage_posts [পাবলিক কমেন্ট রিপ্লাই] [Public Comment Reply]
কমেন্টের ঠিক নিচে "Inbox check koren" লিখে পাবলিক উত্তর দেওয়া। Publishes public replies under user comments.
3. pages_messaging [প্রাইভেট ইনবক্স মেসেজ] [Private DM Message]
কমেন্টকারী কাস্টমারের ইনবক্সে সরাসরি দাম ও অর্ডারের লিংক পাঠানো। Sends direct private messages to comment author's inbox.

⚙️ কীভাবে সেটআপ করবেন? ⚙️ How to Configure in Insaf AI:

  1. ড্যাশবোর্ডের Comment Automation পেজে যান।
  2. যে ফেসবুক পেজে কমেন্ট অটো-রিপ্লাই চালু করতে চান সেটি সিলেক্ট করুন।
  3. Public Reply Template অপশনে যেমন: "Assalamu Alaikum! Inbox check koren vaiya 🙏" টিউন করুন।
  4. Send Private Message অপশনে টিক দিন, যেন কাস্টমারের ইনবক্সে দামের ডিটেইলস চলে যায়।
  1. Navigate to the Comment Automation section in Insaf AI dashboard.
  2. Select the target Facebook Page where you want auto-replies enabled.
  3. Set up your Public Reply Template (e.g. "Hello! Please check your inbox for details 🙏").
  4. Enable Send Private Message to automatically send product prices & order links to customer Messenger.
